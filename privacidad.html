2. Datos que se solicitan

Cuando enviás una consulta, recopilamos nombre, email y teléfono/WhatsApp, junto con la aceptación para contactarte. Si lo autorizás mediante una casilla independiente, también enviamos un resumen de tus respuestas y simulaciones financieras. No se envía ese resumen sin tu elección expresa.

3. Finalidad y base del tratamiento

Usamos los datos para responder consultas y coordinar una conversación solicitada. El envío del resumen financiero es opcional y sirve únicamente para preparar esa conversación. No confirma una reunión reservada ni implica contratar un servicio.

4. Destinatarios y proveedores

Para operar la web utilizamos Cloudflare Workers; para notificaciones por correo utilizamos Resend. La información del formulario se transmite al correo del asesor y el visitante recibe una confirmación. Estos proveedores pueden procesar datos fuera de Argentina, conforme a sus propias condiciones y las salvaguardas que correspondan.
